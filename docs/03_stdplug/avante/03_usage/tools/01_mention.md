# 上下文 mention

avante 核心命令: `@`.

| mention        | 功能                 |
| -------------- | ------------------ |
| `@codebase`    | 启用代码库上下文和 repo map |
| `@diagnostics` | 加入诊断信息             |
| `@file`        | 打开文件选择器            |
| `@quickfix`    | 加入 quickfix 中的文件   |
| `@buffers`     | 加入已打开的 buffers     |
