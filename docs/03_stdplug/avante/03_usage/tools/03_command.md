# command

Avante 原生命令：

| 命令                | 功能                           |
| ----------------- | ---------------------------- |
| `/help`           | 显示 Avante 命令                 |
| `/init`           | 根据项目初始化 `AGENTS.md`          |
| `/clear`          | 清除当前聊天                       |
| `/new`            | 新聊天                          |
| `/compact`        | 压缩 Avante 历史                 |
| `/model`          | 选择模型；ACP provider 下选择 ACP 模型 |
| `/lines 10-30 问题` | 针对指定行提问                      |
| `/commit`         | 将问题改写为提交修改请求                 |

这里和opencode相同的命令会被 avante 命令覆盖.
