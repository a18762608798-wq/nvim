# usage

## perview

* **`空格 c p`**：打开 Markdown 预览，也就是 `<leader>cp`
* **`空格 u m`**：切换编辑器内渲染，也就是 `<leader>um`。
* **gf**: open the linked file with neovim.

## mkdnflow

| 按键          | 功能              |
| ----------- | --------------- |
| `<CR>`      | 打开链接 / 创建链接     |
| `<Tab>`     | 下一个链接           |
| `<S-Tab>`   | 上一个链接           |
| `<BS> (退格键)`      | 返回上一个 Markdown  |
| `<Del>`     | 前进              |
| `]]`        | 下一个 heading     |
| `[[`        | 上一个 heading     |
| `<C-Space>` | toggle checkbox |
| `<leader>p` | 用剪贴板内容创建链接      |
