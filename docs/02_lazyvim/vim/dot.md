# Dot

## Action

What is a modification?

* The last move of cursor.

## Repect

Use `.` to repect the last modification.

### tips

* use `A` to replace `$ + a`.
* use `I` to replace `0 + i`.
* use `O` to replace `k + o`
* use `C` to replece `d$a`
* use `d a w` or `d i w` to delte a word. 
* Use visual mode only necessary.
